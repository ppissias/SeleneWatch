Quick Start (PowerShell Shortcut)
  Launch C:\dev\powershell-selenewatch.lnk
  This automatically runs C:\dev\selenewatch-env.ps1, which imports the MSVC 2026 x64 toolset,
  Qt 6.12.0 kit, CMake, and Ninja into PATH and drops into C:\dev\projects\SeleneWatch.
  From there, you can directly run:
    cmake --preset Debug-x64
    cmake --build out/build/debug
    .\out\build\debug\SeleneWatch.exe

Command Line Build (Manual)
  Open a command prompt or PowerShell, then:

  call "C:\dev\Microsoft Visual Studio\18\Community\VC\Auxiliary\Build\vcvars64.bat"
  cd /d C:\dev\projects\SeleneWatch
  "C:\dev\Microsoft Visual Studio\18\Community\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin\cmake.exe" --preset Debug-x64
  "C:\dev\Microsoft Visual Studio\18\Community\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin\cmake.exe" --build out\build\debug

  (Release uses --preset Release-x64 and out\build\release.)

Running the Executable from the Command Line
  Ensure Qt runtime DLLs and plugins are accessible:
  set PATH=C:\dev\tools\Qt\6.12.0\msvc2022_64\bin;%PATH%
  set QT_PLUGIN_PATH=C:\dev\tools\Qt\6.12.0\msvc2022_64\plugins
  out\build\debug\SeleneWatch.exe
